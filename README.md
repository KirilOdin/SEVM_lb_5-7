# SEVM_lb_5-7
Репозиторий проекта для предмета "Сети электронных вычислительных машин" (3 курс).
Содержит исходный код:
1) сетевого приложения на основе TCP сокетов (Python);
2) сетевого приложения на основе UDP сокетов (Python);
3) реализации FTP-сервера и работы с ним (GuildFTPd + Python).

## Структура проекта (lb 5):
```text
SEVM_lb_5-7
├── config              # Файлы конфигурации (.ini)
├── legacy              # Файлы старой реализации
├── logs                # Файлы конфигурации (.ini)
├── requirements.txt    # Зависимости для проекта
├── run_client.py       # Запуск клиента
├── run_server.py       # Запуск сервера
└── src                 # Исходный код
    ├── client          # Логика и GUI клиента
    ├── common          # Общие модули (логгер, чтение конфигов)
    └── server          # Логика и GUI сервера
```

### Индивидуальное задание (Вариант 6)
Передать на сервер множество чисел. Сервер должен вернуть сумму этих чисел и наименьший делитель этой суммы (кроме 1 и самой суммы). Если делителей нет, вернуть сообщение "сумма простая". Пример: {4,6,8} → сумма = 18, наименьший делитель = 2.
